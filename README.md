# 手机文档扫描与可读性增强系统 (DocScanner-Enhancer)

华南理工大学《数字图像处理》课程设计大作业项目。

## 📖 项目简介
本系统模拟“扫描全能王”类应用的核心图像处理流程，针对手机拍摄的文档照片所普遍存在的**透视畸变、光照阴影、周期性网纹/摩尔纹、运动/散焦模糊、文字模糊**等问题，构建一套纯传统数字图像处理算法驱动的增强与可读性优化流水线。

## 🛠️ 核心功能与算法管线
1. **输入与空间域几何矫正**：透视变换与边缘检测，校正文档倾斜；
2. **色彩空间转换与亮度分离**：RGB 转 HSV/YCbCr，剥离色度并针对亮度分量进行光照平衡；
3. **空间域增强**：局部自适应直方图均衡（CLAHE）、伽马校正与对比度拉伸，消除阴影遮挡；
4. **频率域滤波**：2D-FFT 频域分析，设计陷波滤波器/带阻滤波器消除翻拍网纹与摩尔纹；
5. **退化建模与图像复原**：建立点扩散函数 (PSF)，采用维纳滤波复原散焦/抖动模糊；
6. **文字锐化与二值化**：高频提升/拉普拉斯锐化，Sauvola/Otsu 局部自适应二值化；
7. **综合质量与 OCR 识别率量化评测**：客观指标（PSNR, SSIM）与下游 OCR 准确率评测。
